## 🔐 安全加固配置

### Dependabot 強化配置
```yaml
# .github/dependabot.yml - GitHub Actions 區塊
- package-ecosystem: "github-actions"
  directory: "/"
  schedule:
    interval: "weekly"
    day: "monday" 
    time: "02:00"
  open-pull-requests-limit: 5
  reviewers:
    - "security-team"
  labels:
    - "dependencies"
    - "github-actions"
    - "security"                    # 🆕 新增安全標籤
  commit-message:
    prefix: "ci"
    include: "scope"
  # 🆕 自動合併低風險更新
  allow:
    - dependency-type: "direct"
      update-type: "version-update:semver-patch"
    - dependency-type: "direct"
      update-type: "version-update:semver-minor"
  # 🆕 忽略特定 Actions 主版本更新
  ignore:
    - dependency-name: "actions/*"
      update-types: ["version-update:semver-major"]
```

## 🤖 新增自動化工具

### 1. Dependabot PR 監控 Workflow

**檔案位置**: `.github/workflows/dependabot-monitor.yml`  
**觸發條件**: Dependabot PR 開啟/更新  
**核心功能**:

```yaml
# 智能 PR 分析
- name: 🔍 分析 Dependabot PR 類型
  # 檢測更新類型: github-actions | python | nodejs
  # 判斷更新級別: patch | minor | major

# GitHub Actions 安全檢查  
- name: 🔒 GitHub Actions 安全檢查
  # 檢查不安全版本標籤 (@main, @master, @latest)
  # 驗證已知安全 Actions 清單
  # 評估安全風險等級

# 自動合併條件評估
- name: 🎯 設定自動合併條件
  # 條件 1: patch 級別 + 安全 Actions
  # 條件 2: Python 安全更新 (非 major)
  # 條件 3: 通過所有 CI 檢查
```

**自動合併邏輯**:
```bash
# 安全 GitHub Actions patch 更新
if [[ "$UPDATE_LEVEL" == "patch" ]] && 
   [[ "$UPDATE_TYPE" == "github-actions" ]] && 
   [[ "$SAFE_ACTIONS_FOUND" == "true" ]] && 
   [[ "$UNSAFE_VERSIONS" == "false" ]]; then
   AUTO_MERGE=true
fi
```

### 2. Actions 版本管理腳本

**檔案位置**: `scripts/actions-version-manager.sh`  
**權限**: `chmod +x` (可執行)  
**依賴**: `jq`, `yq`, `gh` (GitHub CLI)

**核心命令**:
```bash
# 完整掃描與報告
./scripts/actions-version-manager.sh --scan --report

# 安全檢查
./scripts/actions-version-manager.sh --security-scan

# 檢查可用更新
./scripts/actions-version-manager.sh --check-updates

# 更新特定 Action
./scripts/actions-version-manager.sh --update actions/checkout

# 備份與還原
./scripts/actions-version-manager.sh --backup
./scripts/actions-version-manager.sh --restore
```

### Quality Summary 總結報告 🆕
```yaml
# 完整的品質檢查報告 (修復版)
- name: Quality Gates Summary
  run: |
    # 智能統計計算
    total_checks=0
    passed_checks=0
    
    # 5 個檢查項目完整追蹤
    # 1. Python Code Quality
    # 2. Code Complexity  
    # 3. Docker Quality
    # 4. Documentation Quality (包含 markdownlint)
    # 5. Commit Quality (僅 PR)
    
    # 自動計算通過率
    pass_rate=$((passed_checks * 100 / total_checks))
    
    # 智能狀態評級
    if [ $pass_rate -eq 100 ]; then
      echo "🎉 所有品質檢查通過！"
    elif [ $pass_rate -ge 80 ]; then
      echo "⚠️ 大部分檢查通過，少數需要關注"
    else
      echo "🚨 多項檢查失敗，需要立即修復"
    fi
```

## 🛡️ 安全配置清單

### 權限最小化
```yaml
permissions:
  contents: read          # 僅讀取倉庫內容
  pull-requests: write    # 僅寫入 PR 評論
  checks: read           # 僅讀取檢查狀態
  actions: read          # 僅讀取 Actions 資訊
```

### 敏感資訊保護
- **GitHub Secrets**: 所有敏感資訊透過 Secrets 管理
- **Token 範圍限制**: GITHUB_TOKEN 最小權限
- **審計追蹤**: 所有自動化操作都有記錄

### 供應鏈安全
- **版本固定**: 所有 Actions 使用固定版本
- **來源驗證**: 僅使用可信任的 Actions 發布者
- **定期更新**: 透過 Dependabot 自動監控更新

## 🔧 故障排除配置

### 常見問題解決方案

#### 1. Action 版本不存在
```bash
# 檢查方法
gh api repos/OWNER/REPO/releases

# 解決方案
# 更新 workflow 文件中的版本號到最新穩定版本
```

#### 2. 權限不足錯誤
```yaml
# 解決方案: 添加必要權限
permissions:
  contents: write
  security-events: write
```

#### 3. 自動合併失敗
```bash
# 檢查 PR 狀態
gh pr view <PR_NUMBER>

# 檢查 CI 狀態  
gh pr checks <PR_NUMBER>

# 手動觸發合併
gh pr merge <PR_NUMBER> --squash
```

### 緊急修復流程
```bash
# 1. 快速診斷
./github-actions-detector.sh --workflow <workflow_name>

# 2. 檢查最新執行
gh run list --workflow=<workflow_name> --limit=5

# 3. 查看詳細日誌
gh run view <run_id> --log

# 4. 緊急修復分支
git checkout -b hotfix/actions-fix
# 進行修復...
git commit -m "fix: 緊急修復 GitHub Actions 問題"
git push origin hotfix/actions-fix
```
