## 詳細問題分析

### 1. Application Layer 問題

#### MessagingService 錯誤 (17個錯誤)
**問題**: `MessagingApplicationService.__init__() missing 1 required positional argument: 'command_executor'`
- **根本原因**: 測試中的服務初始化缺少必要的 command_executor 參數
- **影響**: 整個 MessagingService 測試套件無法執行
- **修復優先級**: 高

#### QueryService 失敗 (3個失敗)
1. **test_validate_query_valid**: 查詢驗證規則過於嚴格，拒絕 PRAGMA 語句
2. **test_get_table_info_specific_table**: SQLite 特定語法與 PostgreSQL 不匹配
3. **test_get_table_info_all_tables**: 資料庫查詢語法差異

### 2. Domain Layer 問題

#### CommandExecutor 失敗 (6個失敗)
**問題**: `Mock object has no attribute 'service_factory'`
- **根本原因**: Mock 物件缺少 service_factory 屬性
- **影響**: 指令執行器的初始化和註冊測試失敗
- **相關**: PostgresCommandHandler 依賴檢查
