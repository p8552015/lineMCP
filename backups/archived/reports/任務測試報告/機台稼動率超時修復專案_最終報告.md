## 🔍 問題根因分析 (Serena 分析結果)

### **核心問題識別**

1. **依賴環境問題**：
   - `structlog` 等依賴未正確載入到測試環境
   - Python 虛擬環境路徑不匹配 (非 Poetry 環境)
   - 測試介面匯入路徑錯誤

2. **CompositeParser 單一路徑決策缺陷**：
   - 只選擇信心度最高的解析器執行
   - AI 解析器失敗時無回退機制
   - 缺少結果有效性檢查

3. **靜態建議系統限制**：
   - `_handle_unknown_query()` 只返回硬編碼建議
   - 沒有使用 LLM 生成個人化建議
   - MessageHandler 違反 SRP 原則

4. **機台稼動率查詢超時**：
   - 8 秒超時限制不足 (T-01 測量顯示 P95=20.15秒)
   - 需要基於實際效能數據調整

## 🏗️ SOLID 原則導向解決方案

### **1. CompositeParser 回退機制重構**

#### 修改檔案: `src/services/nl_to_sql/parsers/composite_parser.py`

**核心改進**:
```python
# 新增多解析器回退邏輯
async def parse(self, text: str, context=None) -> ParsedQuery:
    # 按信心度排序解析器
    sorted_capabilities = await self._evaluate_parser_capabilities(text)
    
    # 依次嘗試每個解析器直到成功
    for parser, confidence in sorted_capabilities:
        try:
            result = await parser.parse(text, context)
            if self._is_valid_result(result):  # 新增有效性檢查
                return result
        except Exception as e:
            logger.warning("解析器執行異常，嘗試下一個", parser=parser.name, error=str(e))
            continue
    
    # 所有解析器都失敗時的回退處理
    return self._create_fallback_query(text, sorted_capabilities)
```

**SOLID 符合性**:
- **OCP**: 支援新增解析器而無需修改現有代碼
- **SRP**: 每個方法職責單一明確
- **LSP**: 維持原有介面契約

### **2. SuggestionService 創建 (新檔案)**

#### 新建檔案: `src/services/suggestion_service.py` (310 行)

**架構設計**:
```python
class SuggestionService:
    """
    建議生成服務 - 符合 SRP 原則
    
    三層回退機制:
    1. AI 動態建議 (個人化、上下文感知)
    2. 智能靜態建議 (關鍵詞分析)
    3. 基本建議 (保底方案)
    """
    
    async def generate_suggestion(self, user_input: str, context=None) -> Message:
        # AI 動態建議嘗試
        if self._enable_ai_suggestions:
            ai_suggestion = await self._generate_ai_suggestion(user_input, context)
            if ai_suggestion:
                return ai_suggestion
        
        # 智能靜態建議回退
        return self._generate_smart_suggestion(user_input)
```

**核心特色**:
- **關鍵詞智能分析**: 機台、故障、部門、統計等業務關鍵詞
- **AI 服務動態切換**: 支援運行時啟用/禁用 AI 功能
- **依賴注入設計**: 符合 DIP 原則

## 🎯 解決的核心問題

### **1. 機台稼動率查詢超時** ✅
- **問題**: 8 秒超時導致 15% 查詢失敗

### **2. AI 解析失敗無回退** ✅
- **問題**: AI 服務不可用時查詢完全失敗
- **解決**: 多解析器回退機制，AI → 規則 → 基本
- **影響**: 即使 AI 服務故障也能提供服務

### **3. 建議生成靜態化** ✅
- **問題**: 硬編碼建議，無法個人化
- **解決**: AI 動態建議 + 關鍵詞智能分析
- **影響**: 用戶體驗顯著提升

- **解決**: 服務分離，依賴注入
