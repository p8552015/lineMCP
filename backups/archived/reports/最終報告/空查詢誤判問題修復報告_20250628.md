## 📋 執行摘要

成功修復 LINE Bot 製造業詞彙庫系統中的空查詢誤判問題。「CNC車床今天不良率」查詢從錯誤返回原始數據庫記錄，修正為正確觸發 LLM 智慧指導回應，完全符合專案最高原則。

## 🔍 問題描述

### 問題現象
- **錯誤行為**：查詢「CNC車床今天不良率」返回原始數據庫記錄（5筆機台資料）
- **預期行為**：應觸發 LLM 生成的智慧指導回應
- **影響範圍**：所有涉及品質指標（不良率、合格率等）的查詢

### 問題嚴重性
- **違反專案最高原則**：「所有空查詢都一定要指引到 Gemini/OpenAI 的大語言模型生成的回覆」
- **用戶體驗差異**：相同邏輯的查詢（OEE指標 vs 不良率）產生不一致結果

## 🔬 問題分析過程

### 第一階段：深度診斷（使用 Serena MCP）

1. **查詢流程追蹤**
   ```
   用戶輸入 → AI解析器 → 組合解析器 → NL-to-SQL服務 → 訊息處理器 → 回應
   ```

2. **根本原因發現**
   - AI 解析器的系統提示詞未正確配置品質指標識別
   - AI 模型返回純文字而非要求的 JSON 格式
   - CompositeParser 的權重計算邏輯有誤
   - MessageHandlerDI 的 UNKNOWN 查詢處理邏輯缺陷

### 第二階段：逐層修復

#### 1. AI 解析器修復 (ai_enhanced_parser.py)
```python
# 修復前：使用預設提示詞
enhanced_result = await self._ai_service.enhance_natural_language_query(text)

# 修復後：使用自定義提示詞
enhanced_result, confidence = await self._ai_service.query_with_custom_prompt(
    text, self._system_prompt
)
```

**系統提示詞強化**：
- 明確識別品質指標為不支援查詢
- 強制要求 JSON 格式回應
- 添加品質相關關鍵詞警告

#### 2. CompositeParser 權重修復
```python
# 修復前：未考慮權重
candidates.append({
    'parser_name': parser_name,
    'result': result,
    'confidence': result.confidence
})

# 修復後：考慮權重調整信心度
weight = self._strategy_weights.get(parser_name, 1.0)
weighted_confidence = min(1.0, base_confidence * weight)
```

#### 3. MessageHandlerDI 核心邏輯修復
```python
# 修復前：跳過 UNKNOWN 查詢的 LLM 指導
if parsed_query and parsed_query.query_type != QueryType.UNKNOWN:
    guidance = await self.nl_service._generate_user_guidance(...)

# 修復後：為 UNKNOWN 查詢生成專門指導
if parsed_query:
    if parsed_query.query_type == QueryType.UNKNOWN:
        guidance = await self.nl_service._generate_user_guidance(
            QueryType.PRODUCTION_STATS,
            {"quality_metric": "unsupported", "original_query": message_text},
            message_text,
        )
```
