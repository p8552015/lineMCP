## 🚀 快速開始

### 遇到問題時的標準流程
1. **📋 首先閱讀**: [問題解決流程標準指南](./問題解決流程標準指南.md)
2. **🔍 識別問題類型**: 
   - 測試環境正常，生產環境異常 → [測試環境vs生產環境差異排查手冊](./測試環境vs生產環境差異排查手冊.md)
   - AI模型切換不正常 → [AI模型備用機制故障排除指南](./AI模型備用機制故障排除指南.md)
3. **🔧 執行修復**: 按照對應指南的步驟執行
4. **✅ 驗證修復**: 確保問題完全解決
5. **📝 更新文檔**: 如遇到新情況，更新相關指南

### 常用快速命令
```bash
# 問題診斷
./spec/scripts/diagnose-env-diff.sh

# 修復環境差異
./spec/scripts/fix-env-diff.sh  

# 測試備用機制
python test_fallback_mechanism.py

# 完整驗證
./quick-test-vocabulary.sh
```

## 📊 問題分類速查表

### 🔴 高優先級問題 (立即處理)
- **語法錯誤**: 導致服務無法啟動
- **服務崩潰**: 用戶無法使用
- **安全漏洞**: 數據或系統風險

**處理**: 立即停止服務 → 修復 → 測試 → 部署

### 🟡 中優先級問題 (24小時內)
- **功能異常**: 部分功能不正常
- **性能問題**: 回應時間過長
- **環境差異**: 測試與生產不一致

**處理**: 分析根因 → 制定方案 → 修復 → 驗證

### 🟢 低優先級問題 (計劃處理)
- **優化建議**: 代碼改進
- **文檔更新**: 說明完善
- **監控增強**: 系統觀察

**處理**: 列入開發計劃 → 定期回顧

## 🛠️ 工具與腳本

### 自動化診斷工具
```bash
# 創建診斷腳本目錄
mkdir -p spec/scripts

# 診斷環境差異
spec/scripts/diagnose-env-diff.sh

# 修復環境差異  
spec/scripts/fix-env-diff.sh

# 診斷備用機制
spec/scripts/diagnose-fallback.sh

# 修復備用機制
spec/scripts/fix-fallback.sh
```

### 測試驗證工具
```bash
# 語法檢查
python -m py_compile apps/bot/src/services/*.py

# 功能測試
./quick-test-vocabulary.sh

# 性能測試
./test_ai_switch_simple.py

# 完整測試
pytest tests/ -v
```
