## 模板使用說明

### 如何使用此模板
1. 複製此模板到 `decisions/` 目錄
2. 重新命名為 `XXX-descriptive-title.md` (XXX 為三位數編號)
3. 填寫所有相關部分
4. 更新 [ADR 索引](./README.md)

### 編號規則
- 使用三位數編號 (001, 002, 003...)
- 按時間順序遞增
- 不要重複使用編號

### 狀態定義
- **提議**: 決策尚在討論中
- **接受**: 決策已被接受並實施
- **棄用**: 決策不再適用但保留記錄
- **被取代**: 被新的 ADR 取代
