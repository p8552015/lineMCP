```json

  "query_preview": "",
```

- SQL 查詢為空字串，導致 MCP 服務器直接拒絕

## 📋 測試腳本範例

### 空查詢檢測腳本
```bash
#!/bin/bash
# 檢測系統是否產生空查詢

echo "🔍 檢測空查詢問題..."
python3 -c "
from src.services.nl_to_sql.builders.sql_query_builder import SQLQueryBuilder
from src.services.nl_to_sql.models.query_models import QueryType

# 測試查詢建構
try:
    builder = SQLQueryBuilder()
    query = builder.build(QueryType.ALL_MACHINES, {})
    
    if not query or len(query.strip()) == 0:
        print('❌ 發現空查詢問題')
        exit(1)
    else:
        print(f'✅ 查詢建構正常: {query[:50]}...')
        exit(0)
except Exception as e:
    print(f'❌ 查詢建構失敗: {e}')
    exit(1)
"
```
