# 製造業詞彙庫使用者更新指南

## 🎯 使用目標

此指南幫助使用者輕鬆收集和更新製造業詞彙庫，讓系統能夠更準確地理解和解譯複雜的製造業查詢，如「M001機台稼動率」。

## 📊 系統架構概覽

### 核心功能
- **智能關鍵字識別**：自動從查詢中提取機台編號、指標類型、時間範圍等
- **多欄位同時提取**：一次查詢可提取多個相關資料欄位
- **LLM 增強解譯**：使用人工智慧提升複雜查詢的理解能力
- **動態學習機制**：從使用者回饋中持續改善解譯準確度

### 詞彙庫結構
```
製造業詞彙庫
├── 設備機台 (equipment)
│   ├── 機台編號 (M001, M002, 生產線A...)
│   └── 機台類型 (CNC車床, 銑床...)
├── 生產指標 (metrics) 
│   ├── 稼動率, OEE, 不良率, 產量
│   └── 各指標的計算公式和單位
├── 時間維度 (time_dimensions)
│   ├── 即時, 今天, 本週, 本月
│   └── 特定時間格式和範圍
└── 組織結構 (organizational)
    ├── 部門 (生產部門, 品質部門...)
    └── 班次 (早班, 晚班...)
```

## 🛠️ 詞彙更新方法

### 方法一：直接編輯 YAML 檔案

**檔案位置**：`/apps/bot/src/services/nl_to_sql/config/manufacturing_vocabulary_database.yaml`

**新增詞彙範例**：
```yaml
equipment:
  machine_identifiers:
    - term: "M003"  # 新增機台
      type: "machine_id"
      synonyms: ["M-003", "機台M003", "Machine M003", "鑽床C"]
      extraction_patterns:
        - "M\\d{3}"
        - "鑽床[A-Z]"
      field_mappings:
        machine_id: "M003"
        machine_type: "DRILLING_MACHINE"
        department: "production_line_2"
      confidence_weight: 0.95
```

### 方法二：使用 Python API

**程式化新增詞彙**：
```python
from intelligent_vocabulary_interpreter import IntelligentVocabularyInterpreter, VocabularyEntry

# 初始化解譯器
interpreter = IntelligentVocabularyInterpreter("manufacturing_vocabulary_database.yaml")

# 新增詞彙條目
new_entry = VocabularyEntry(
    term_id="equipment_machine_M004",
    primary_term="M004",
    synonyms=["M-004", "機台M004", "射出成型機D"],
    term_type="machine_id",
    extraction_patterns=["M\\d{3}", "射出成型機[A-Z]"],
    field_mappings={
        "machine_id": "M004",
        "machine_type": "INJECTION_MOLDING",
        "department": "production_line_3"
    },
    confidence_weight=0.92
)

# 新增到系統
success = interpreter.add_vocabulary_entry(new_entry)
if success:
    print("詞彙新增成功！")
```

### 方法三：使用 Excel 批量匯入

**準備 Excel 檔案**：
```
| 詞彙 | 類型 | 同義詞 | 提取模式 | 機台編號 | 機台類型 | 部門 | 信心度 |
|------|------|--------|----------|----------|----------|------|--------|
| M005 | machine_id | M-005,機台M005 | M\\d{3} | M005 | LASER_CUTTER | production_line_4 | 0.90 |
```

**匯入程式碼**：
```python
from vocabulary_batch_importer import VocabularyBatchImporter

importer = VocabularyBatchImporter()

print(f"成功匯入 {result.success_count} 個詞彙")

```

## 📋 詞彙新增檢查清單

### 基本檢查項目
- [ ] **詞彙唯一性**：確認新詞彙不與現有詞彙重複
- [ ] **同義詞完整性**：包含所有可能的表達方式
- [ ] **提取模式正確**：正則表達式模式測試通過
- [ ] **欄位映射完整**：所有相關欄位都有對應的值
- [ ] **信心度合理**：設定 0.0-1.0 之間的適當信心度

### 進階驗證項目
- [ ] **語義一致性**：新詞彙與同類別詞彙語義一致
- [ ] **業務邏輯正確**：欄位值符合實際業務規則
- [ ] **測試案例通過**：使用新詞彙的查詢能正確解譯

## 🧪 測試新增詞彙

### 測試腳本範例
```python
async def test_new_vocabulary():
    """測試新增的詞彙是否正常工作"""
    interpreter = IntelligentVocabularyInterpreter("manufacturing_vocabulary_database.yaml")
    
    # 測試案例
    test_cases = [
        "M004機台稼動率",  # 測試新機台
        "射出成型機D今天的產量",  # 測試同義詞
        "生產線三本週OEE指標"  # 測試新部門
    ]
    
    for query in test_cases:
        result = await interpreter.interpret_query(query)
        
        print(f"查詢：{query}")
        print(f"  機台：{result.extracted_fields.machine_id}")
        print(f"  指標：{result.extracted_fields.metric_type}")
        print(f"  信心度：{result.confidence:.2f}")
        print(f"  狀態：{'✅ 通過' if result.confidence > 0.8 else '❌ 需要改進'}")
        print()

# 執行測試
import asyncio
asyncio.run(test_new_vocabulary())
```

## 📊 詞彙分類指南

### 設備機台 (Equipment)
**適用範圍**：所有實體生產設備

**必填欄位**：
- `machine_id`: 唯一機台編號
- `machine_type`: 機台類型
- `department`: 所屬部門

**命名規範**：
- 機台編號：字母+數字組合（如 M001, LINE-A）
- 機台類型：使用標準製造業術語（如 CNC_LATHE, MILLING_MACHINE）

**範例詞彙**：
```yaml
- term: "包裝線A"
  synonyms: ["Pack-A", "包裝設備A", "Packaging Line A"]
  field_mappings:
    machine_id: "PACK_A"
    machine_type: "PACKAGING_LINE"
    department: "packaging"
```

### 生產指標 (Metrics)
**適用範圍**：所有可量化的生產績效指標

**必填欄位**：
- `metric_type`: 指標類型標識
- `metric_category`: 指標分類
- `unit`: 量測單位

**標準指標類型**：
- `utilization_rate`: 稼動率
- `oee`: 整體設備效率
- `defect_rate`: 不良率
- `throughput`: 產量
- `cycle_time`: 週期時間
- `setup_time`: 換線時間

**範例詞彙**：
```yaml
- term: "換線時間"
  synonyms: ["setup time", "調機時間", "切換時間"]
  field_mappings:
    metric_type: "setup_time"
    metric_category: "efficiency"
    unit: "minutes"
  calculation_formula: "end_setup_time - start_setup_time"
```

### 時間維度 (Time Dimensions)
**適用範圍**：所有時間相關的查詢條件

**必填欄位**：
- `time_period`: 時間週期類型
- `time_range`: 具體時間範圍

**標準時間類型**：
- `real_time`: 即時
- `hourly`: 每小時
- `daily`: 每日
- `weekly`: 每週
- `monthly`: 每月
- `quarterly`: 每季
- `yearly`: 每年

**範例詞彙**：
```yaml
- term: "上個月"
  synonyms: ["last month", "前一個月", "上月"]
  field_mappings:
    time_period: "monthly"
    time_range: "last_month"
```

### 組織結構 (Organizational)
**適用範圍**：部門、班次、人員等組織資訊

**部門標準名稱**：
- `production`: 生產部門
- `quality`: 品質部門
- `maintenance`: 維修部門
- `planning`: 計劃部門
- `logistics`: 物流部門

**班次標準代碼**：
- `A`: 早班 (08:00-16:00)
- `B`: 晚班 (16:00-24:00)
- `C`: 夜班 (24:00-08:00)

**正則表達式範例**：
```yaml

```

## 🚨 常見錯誤與解決方案

### 錯誤 1：詞彙重複
**症狀**：系統提示詞彙已存在
**解決方案**：
1. 檢查現有詞彙庫是否已包含相同主詞彙
2. 考慮將新詞彙作為同義詞加入現有條目
3. 確認是否為不同語境下的相同詞彙

### 錯誤 2：提取模式無效
**症狀**：正則表達式編譯失敗
**解決方案**：
1. 使用線上正則表達式測試工具驗證
2. 確保特殊字元正確轉義
3. 測試模式是否能匹配預期的文字

**常見模式錯誤**：
```python
# ❌ 錯誤：沒有轉義特殊字元
"M001"  # 只匹配字母 M 和 3 個任意字元

# ✅ 正確：轉義特殊字元
"M\\d{3}"  # 匹配 M 後面跟 3 個數字
```

### 錯誤 3：欄位映射不正確
**症狀**：解譯結果與預期不符
**解決方案**：
1. 檢查欄位名稱是否與系統定義一致
2. 確認欄位值格式符合規範
3. 驗證欄位之間的邏輯關係

### 錯誤 4：信心度設定不當
**症狀**：高質量詞彙信心度低，或低質量詞彙信心度高
**解決方案**：
1. 參考現有同類詞彙的信心度設定
2. 考慮詞彙的使用頻率和重要性
3. 進行 A/B 測試找出最佳信心度

**信心度參考指南**：
- **0.95-1.0**: 標準機台編號、核心指標
- **0.85-0.94**: 常用同義詞、標準術語
- **0.70-0.84**: 地方性術語、非標準表達
- **0.50-0.69**: 實驗性詞彙、低頻術語
