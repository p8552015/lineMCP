# 🔍 深度問題調試分析

使用 Serena MCP 工具對 **$ARGUMENTS** 進行深度分析，找出問題根源並提供解決方案。

## 🎯 分析目標

針對問題：**$ARGUMENTS**

## 📋 Serena 深度分析流程

### 階段 1: 全域搜尋與定位
1. **使用 `search_for_pattern`** 搜尋相關程式碼模式
2. **使用 `find_symbol`** 定位相關的類別、函數、變數
3. **使用 `get_symbols_overview`** 獲取整體架構概覽

### 階段 2: 檔案深度分析
1. **使用 `read_file`** 詳細檢查相關檔案
2. **使用 `find_referencing_symbols`** 找出依賴關係
3. **分析程式碼邏輯和資料流**

### 階段 3: 問題根因分析
1. **識別錯誤模式** - 語法、邏輯、架構問題
2. **追蹤執行路徑** - 找出問題發生的具體位置
3. **分析依賴關係** - 檢查模組間的相互影響

### 階段 4: 解決方案設計
1. **評估修復影響範圍**
2. **設計最小侵入性修復**
3. **考慮向後相容性**
