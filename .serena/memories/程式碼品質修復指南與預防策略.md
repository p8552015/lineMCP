# 程式碼品質修復指南與預防策略

## 立即修復行動計劃

### 1. E501 錯誤修復策略
**問題**: 行長度超過 88 字符限制

**修復方法**:
```python
# ❌ 錯誤示例
very_long_method_name_with_many_parameters(param1, param2, param3, param4, param5)

# ✅ 正確修復
very_long_method_name_with_many_parameters(
    param1, param2, param3, 
    param4, param5
)

# ❌ 長字串錯誤
long_string = "這是一個非常長的字串，超過了88個字符的限制，需要進行適當的分割處理"

# ✅ 字串修復
long_string = (
    "這是一個非常長的字串，超過了88個字符的限制，"
    "需要進行適當的分割處理"
)
```

### 2. N818 錯誤修復策略
**問題**: 異常類別缺少 "Error" 後綴

**修復方法**:
```python
# ❌ 錯誤命名
class ValidationException(Exception):
    pass

# ✅ 正確命名  
class ValidationError(Exception):
    pass
```

### 3. 其他錯誤修復
- **F401**: 移除未使用的導入
- **E402**: 將導入移至檔案頂部
- **E722**: 使用具體的異常類型

## 預防策略實施指南

### 1. 開發環境配置

#### Pre-commit Hooks 設置
```bash
# 安裝 pre-commit
pip install pre-commit

# 創建 .pre-commit-config.yaml
cat > .pre-commit-config.yaml << EOF
repos:
  - repo: https://github.com/psf/black
    rev: 23.3.0
    hooks:
      - id: black
        args: [--line-length=88]
        
  - repo: https://github.com/astral-sh/ruff-pre-commit
    rev: v0.0.270
    hooks:
      - id: ruff
        args: [--fix, --exit-non-zero-on-fix]
        
  - repo: https://github.com/pre-commit/mirrors-mypy
    rev: v1.3.0
    hooks:
      - id: mypy
        additional_dependencies: [types-all]
EOF

# 安裝 hooks
pre-commit install
```

#### VS Code 設置
```json
// .vscode/settings.json
{
    "python.linting.enabled": true,
    "python.linting.ruffEnabled": true,
    "python.formatting.provider": "black",
    "python.formatting.blackArgs": ["--line-length=88"],
    "editor.formatOnSave": true,
    "editor.rulers": [88],
    "python.linting.ruffArgs": ["--line-length=88"]
}
```

### 2. CI/CD 優化策略

#### 早期失敗原則
```yaml
# .github/workflows/quality-check.yml
name: Code Quality Check
on: [push, pull_request]

jobs:
  quality:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'
      
      - name: Install dependencies
        run: |
          pip install poetry
          poetry install
      
      - name: Run Black (Fail Fast)
        run: poetry run black --check --diff src/
      
      - name: Run Ruff (Fail Fast)  
        run: poetry run ruff check src/ --output-format=github
      
      - name: Run MyPy (Fail Fast)
        run: poetry run mypy src/
```

### 4. 開發最佳實踐

#### 命名規範
- **類別名稱**: PascalCase，異常類別必須以 "Error" 結尾
- **方法名稱**: snake_case，避免過長的名稱
- **變數名稱**: snake_case，使用描述性名稱

#### 代碼組織
- **行長度**: 嚴格遵守 88 字符限制
- **導入順序**: 標準庫 → 第三方庫 → 本地模組
- **方法長度**: 單個方法不超過 50 行

#### 異常處理
- 使用具體的異常類型，避免裸露 except
- 異常類別名稱必須以 "Error" 結尾
- 提供有意義的錯誤訊息
